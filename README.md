# Custom Colors 1.1.0

Geode-мод для Geometry Dash 2.2081. Целевой SDK: Geode 5.11.2.

## Цветовые каналы

- **P1** — первый цвет иконки игрока.
- **P2** — второй цвет иконки игрока.
- **Glow** — цвет свечения иконки.

P1 и P2 — два канала одной иконки. Это не обозначения первого и второго игроков в Dual.

## Профили `.ccprofile`

1. Открой настройки мода в Geode.
2. При желании введи пароль в поле «Пароль профиля».
3. Выбери «Экспортировать профиль» и укажи имя/место файла.
4. Для загрузки профиля введи тот же пароль (если он был задан) и выбери файл в поле «Импортировать профиль».
5. Импорт заменяет текущие P1, P2 и Glow.

Файл `.ccprofile` — JSON с версией формата и тремя HEX-цветами. Парольная проверка предотвращает обычный импорт без правильного пароля, но **не шифрует содержимое файла**: цвета внутри файла можно прочитать текстовым редактором. Не используй эту функцию для хранения секретов.

## Сборка через GitHub Actions

1. Загрузи всё содержимое этой папки в корень репозитория GitHub.
2. Открой вкладку **Actions**.
3. Запусти workflow **Build Custom Colors Android**.
4. После успешного завершения скачай artifact `Custom-Colors-Android64`.
5. Внутри будет `.geode` для Android ARM64.
